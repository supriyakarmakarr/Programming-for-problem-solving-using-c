### 🟣 About This Repository

This repository is a collection of **C programs** written as part of my first-semester **Problem Solving using C** assignment. Each program tackles a small, specific problem — from basic syntax practice to logic-building exercises — and is kept in its own file for easy navigation.

The goal isn't just to submit an assignment, but to actually get comfortable thinking in C: breaking a problem down, writing clean logic, and testing edge cases.

---

### 🟣 Problems Solved

| # | Problem | Concept Used | File |
|---|---|---|---|
| 1 | Leap Year Checker | Conditionals | `leap_year.c` |
| 2 | Grade / Marks Calculator | Conditionals, Arithmetic | `grade_calculator.c` |
| 3 | Income Tax Slab Calculator | Conditionals, Slabs Logic | `tax_calculator.c` |
| 4 | Roman Numeral Converter | Loops, Arrays, Strings | `roman_numeral.c` |
| 5 | Linked List Addition | Pointers, Structures, Dynamic Memory | `linked_list_addition.c` |
| 6 | Resistor / Circuit Network Analysis | Ladder & Bridge Networks, Star-Mesh Method | `circuit_analysis.c` |

### 🟣 How to Run

```bash
# Clone the repository
git clone https://github.com/supriyakarmakarr/problem-solving-in-c.git
cd problem-solving-in-c

# Compile any program
gcc leap_year.c -o leap_year

# Run it
./leap_year
```
